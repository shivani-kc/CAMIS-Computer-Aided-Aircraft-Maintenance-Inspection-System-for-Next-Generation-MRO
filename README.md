# CAMIS-Computer-Aided-Aircraft-Maintenance-Inspection-System-for-Next-Generation-MRO
CAMIS: AI-driven aircraft inspection platform for MRO facilities. It combines a 7-stage OpenCV image pipeline, SAHI, and RT-DETR-L transformers to detect micro-cracks and damage. It features a Gemma LLM for automated reporting and Power BI integration for fleet-wide spatial tracking.
